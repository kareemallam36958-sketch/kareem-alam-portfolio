KAREEM ALAM PORTFOLIO
=====================

الملفات دي كلها ملكك. موقع عادي من HTML و CSS و JavaScript، من غير أي اعتماد على Claude.

المحتويات
---------
index.html   الموقع كله (التصميم والنصوص والحركة) في ملف واحد
img/         صورك وصور المشاريع واللوجوهات
doc/         صفحات سكريبت مُمكّن وملف فيلا ليلي

تفتحه إزاي
----------
دبل كليك على index.html وهيفتح في المتصفح. لازم فولدر img و doc يفضلوا جنبه.
الخطوط بتتحمل من Google Fonts، فمحتاج نت عشان تظهر بالشكل المظبوط.

ترفعه إزاي ببلاش ومن غير دومين
-------------------------------
أي استضافة للمواقع الثابتة تنفع. أسهل اختيارين:
1) Netlify: اسحب الفولدر كله على صفحة الرفع عندهم وهيديك لينك.
2) GitHub Pages: ارفع الملفات في repository وفعّل Pages من الإعدادات.
راجع شروط وحدود الباقة المجانية عند أي خدمة قبل ما تعتمد عليها.

تعدل فيه إزاي
-------------
افتح index.html بأي محرر نصوص (Notepad أو VS Code):
- المشاريع: دور على  var P=[  وعدل الاسم، السنة، الوصف، واللينكات.
- المبادئ الخمسة: دور على  var BELIEFS=[
- الألوان: أول الملف تحت  :root  (paper, ink, umber, flame, amber).
